# Color system

Define semantic roles and permitted pairings before assigning HEX values. Include surface, ink, emphasis and reverse needs. Preserve the primary vector palette in six-digit sRGB and use role names for product CSS. Note where accents are decorative only.

For print, specify substrate, minimum size and clear space, knockouts, and any single-ink requirement. Obtain the printer’s output intent and proof. Treat RGB as the digital source and document any provisional CMYK or spot matches separately from printer-approved values. Never derive production claims from an unprofiled conversion.
