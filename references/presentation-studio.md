# Presentation Studio

Use `present PROJECT OUTPUT` after rendering the shortlist. The studio lays out an editorial comparison with a full-size mark, reversed art, 16/32 px samples and a short rationale per candidate. Present the board alongside the retained shortlist notes and tradeoffs. Use the PNG for review and the SVG for scalable viewing. Presentation SVGs contain layout text and embedded validated artwork. Editable masters live separately in the candidate round.

Use `applications PROJECT ID OUTPUT` for deterministic digital and print scenarios from the chosen horizontal and stacked compositions. Set the titles, labels and copy for the actual brief. Keep the comparison of the clean vectors accessible alongside these context studies. Before final approval, show representative placements and identify the applications still awaiting a real proof.

If a host can generate mockups, use the [image integration](integrations.md). Label them as generated or composited, record source rights and confirm that the mark is faithfully applied. Image tools may distort lettering or silhouette. A production print proof requires the actual substrate and output intent.
