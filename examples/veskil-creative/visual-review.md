# Veskil visual review

The comparison, proof and application PNGs were rendered with librsvg 2.62.1 and Cairo 1.18.4. The selected direction has a recorded critique and a rerender. See the selected rounds’ inspection records for pixel sizes, visual observations and the refinement decision.

Primary color belongs on Warm Paper. The dark-ground primary test exposes loss of the pine band, so use reverse white on dark surfaces. At compact sizes prefer the mark over either lockup.

Print proof, trademark clearance and target-language type coverage are outside this fictional benchmark.
