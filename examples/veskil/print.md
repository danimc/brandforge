# Veskil print specification

Cover stamp uses the black SVG with an open seam and a target minimum mark width of 8 mm. Start at 35 mm for the horizontal lockup. Allow at least one eighth of the SVG artboard height around artwork. Request a physical proof at minimum size on the actual cover stock to check ink spread and the seam.

For process printing, supply the source sRGB references Pine Ink #12352B, Spruce #246B54, Rust #9D3D27 and Warm Paper #F8F1E2. Convert using the printer’s agreed ICC profile and verify separations, total ink, stock and proof. No CMYK or spot recipes have been assigned. Printer signoff remains open.
